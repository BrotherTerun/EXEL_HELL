# EXEL HELL Devlog #2 — как не написать Excel вместо игры

Есть неприятная ловушка в концептах, которые имитируют знакомые программы.

Очень легко решить:

> «Раз игра выглядит как Excel, значит сначала нужно нормально реализовать Excel».

А потом через три дня у тебя есть отличный редактор электронных таблиц и примерно ноль игры.

Поэтому первым техническим решением EXEL HELL стало довольно жестокое ограничение:

==**таблица должна выглядеть достаточно настоящей, но быть устроена только настолько сложно, насколько этого требует игра.**==

## Что действительно нужно

На уровне core-механики нам нужны:

- сетка ячеек;
    
- адреса ячеек;
    
- выделение отдельных клеток и диапазонов;
    
- значения;
    
- несколько игровых операций;
    
- возможность повреждать и изменять структуру таблицы;
    
- система аномалий.
    

Этого достаточно, чтобы начать проверять главный вопрос:

==**может ли взаимодействие с таблицей само по себе стать gameplay?**==

## А настоящий Excel-парсер?

Нет.

По крайней мере пока.

Вместо условных сотен функций будет небольшой набор игровых команд.

Например, если в настоящей электронной таблице `SUM` — просто вычисление, то здесь знакомая семантика может стать основой способности.

То же касается ошибок.

`#REF!` особенно удачно подходит для игры, потому что само обозначение уже говорит игроку:

**что-то со структурой данных фундаментально сломано.**

Остаётся сделать так, чтобы это было не просто декоративной надписью.

## Почему почти нет арта

Ещё одно полезное свойство концепта: интерфейс здесь одновременно является окружением.

Нам не нужно сейчас моделировать:

- офис;
    
- стол;
    
- компьютер;
    
- сотрудника;
    
- двадцать одинаковых шкафов с документами.
    

Основной экран и есть игровой мир.

Поэтому время можно тратить на то, что непосредственно влияет на ощущение игры:

- движение ячеек;
    
- выделение;
    
- повреждение таблицы;
    
- ошибки;
    
- всплывающие окна;
    
- сообщения начальника;
    
- звук клавиатуры и системных уведомлений.
    

==То есть арт-дирекшн здесь возникает не из количества контента, а из поведения интерфейса.==

==Для джема звучит почти подозрительно рационально.==

==Посмотрим, сколько времени потребуется таблице, чтобы наказать нас за эту самоуверенность.==
