# HOOK
EXCEL HELL = пошаговый тактический пазл внутри таблицы
Бухгалтер пытается закончить отчёт внутри псевдо-Excel, пока таблица постепенно сходит с ума. Формулы превращаются в правила физики таблицы, ошибки — в угрозы, сама структура документа начинает сопротивляться игроку.
## Core Verb
Выбирать диапазоны клеток и применять к ним формулы/операции. Одни и те же офисные инструменты используются одновременно и для выполнения отчёта, и для борьбы с аномалиями.
# Core-loop
рабочая задача → появляется/распространяется аномалия → выбираем диапазон → применяем формулу → структура таблицы изменяется → спасаем нужные данные/продвигаем отчёт → новая проблема.
Generate Intent → показать угрозу → Player Action → Resolve Action → Resolve Anomaly → Age Corruption → Generate Next Intent → Check Win/Lose
## WOW-моменты уже придуманы:
- `SUM` впервые буквально стягивает содержимое нескольких клеток;
- `#REF!` начинает физически пожирать соседние клетки;
- целый столбец пытается сбежать за край окна;
- и ровно в этот момент приходит сообщение начальника: «отчёт будет сегодня?».
# Общее направление визуала
Игра должна сначала выглядеть как убедительно скучная корпоративная spreadsheet-программа. Психоз возникает не из хоррор-декораций, а из постепенного нарушения знакомых правил интерфейса: значения меняются без команды игрока, границы клеток съезжают, выделение начинает вести себя неправильно, строки и столбцы физически деформируются, системные сообщения вторгаются в рабочую область.

Базовый интерфейс остаётся максимально читаемым: светлая таблица, нейтральные серо-белые панели, один спокойный акцентный цвет, моноширинный шрифт для формул и значений. Чем дальше заходит психоз, тем сильнее UI нарушает собственную геометрию, но важная игровая информация всегда остаётся различимой.
# MVP
Фиксируем MVP без дальнейшего брейншторма:
- поле **10×10**;
- часть клеток содержит исходные числа;
- есть **3 итоговых показателя отчёта**;
- день = условно **15 ходов**;
- любое игровое действие = 1 ход;
- после хода игрока действует таблица;
- единственная аномалия MVP — `#REF!`;
- заражение: `Normal → #REF! → Destroyed`;
- `#REF!` распространяется на соседние клетки;
- победа: правильно заполнить обязательные показатели и нажать **SUBMIT**;
- поражение: дедлайн либо потеря критически необходимых данных.
- курсор и выделение диапазонов;
- одна основная задача — заполнить/сохранить необходимую часть отчёта;
- проигрыш — разрушены критические клетки или закончился рабочий день;
- **никакого настоящего Excel parser'а**.
Инструменты игрока пока:
1. **SUM(range → target)**;
2. **CUT(cell)**;
3. **PASTE(cell)**;
4. **DELETE(cell)**.
`SORT`пока **не делаем**. Он хороший, но не нужен для доказательства core.
**Результат 25-й минуты:** правила больше сегодня не меняем, пока prototype не докажет, что они плохие.
# Основные механики:
- **Работа с таблицей.** Игрок выбирает одиночные клетки или прямоугольные диапазоны и применяет к ним офисные операции.
- **Пошаговая экономика.** Выделение, наведение и выбор инструмента бесплатны; подтверждённая операция тратит один рабочий ход.
- **Telegraphed Threat.** Перед действием игрок видит, какую клетку `#REF!` атакует следующей. После действия угроза реализуется. Это напрямую берём из логики _Into the Breach_, где атаки противника заранее показываются игроку, превращая бой в детерминированную задачу, а не угадайку.
- **Спасение данных.** Игрок может переносить необходимые значения через `CUT → Clipboard → PASTE`; перенос занимает два хода и создаёт риск.
- **Локализация заражения.** `DELETE` позволяет пожертвовать клеткой/данными, чтобы остановить или перенаправить распространение ошибки.
- **Преобразование данных.** `SUM` одновременно выполняет настоящую задачу отчёта и меняет состояние игрового поля.
- **Сборка отчёта.** Для победы необходимо получить три конкретных итоговых значения и поместить их в report cells.
- **Ранняя отправка.** Игрок в любой момент может нажать `SUBMIT`; правильный отчёт завершает уровень, ошибочный имеет последствия.
- **Дедлайн.** Рабочий день имеет конечное количество ходов, поэтому невозможно бесконечно спасать таблицу.
- **Эскалация интерфейса.** По мере прохождения сами элементы spreadsheet UI становятся частью игрового пространства и начинают нарушать ожидаемое поведение.
