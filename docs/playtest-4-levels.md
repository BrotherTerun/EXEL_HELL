# EXCEL HELL — внешний плейтест: 4 уровня

Цель билда: дать новому игроку один непрерывный проход из четырёх уровней без ручной смены Config в Inspector.

## Состав

1. **Обычный отчёт** — Salary Total + Bonuses >= 5. 12 ходов. `#REF!` отключён. Уровень обучает базовым операциям и впервые требует фильтрации данных через физическую перестройку таблицы: ненужные значения премий нужно убрать из рабочего диапазона через CUT/PASTE перед SUM.
2. **Срочная сверка** — Salary Total + Bonuses >= 5. 13 ходов. `#REF!` включён после безопасного старта; знакомая условная задача теперь проверяется под угрозой.
3. **Несходящиеся данные** — Salary of max overtime + Salaries where Hours < 40. 18 ходов. `#REF!` приходит раньше; уровень проверяет semantic-задачи и перестройку таблицы.
4. **Финальная сверка** — Salaries where Hours < 40 + Overtime Total + Bonus Total. 20 ходов. Три параллельные задачи под активным `#REF!`: одна условная semantic-задача и две полные суммы.

После принятого отчёта появляется `NEXT LEVEL`. После четвёртого уровня — `PLAYTEST COMPLETE`. `RESET` перезапускает текущий уровень.

Ожидаемые ответы скрыты в build-конфигурации. Spawn debug также выключен.

## Сборка

В Build Settings уже включена единственная runtime-сцена `Assets/Scenes/SampleScene.unity`. Для Windows достаточно обычного `File -> Build Profiles/Build Settings -> Windows -> Build` либо playtest build helper.

Рекомендуемый формат распространения: папка Windows build целиком в ZIP. Не передавать тестировщику таблицу ожидаемых ответов или smoke-test документы.

## Что фиксировать

- Ходы победного прохождения и количество рестартов по каждому уровню.
- Где игрок впервые понял назначение SORT, SUM и зелёных полей отчёта.
- Какие операции реально использовал и какие проигнорировал.
- Сколько действий было сделано именно из-за `#REF!`.
- Когда игрок впервые изменил первоначальный план из-за угрозы.
- Возникали ли несколько разумных вариантов решения.
- Появлялась ли стратегия, которую игрок затем повторял автоматически.

Не объяснять механику сверх встроенного обучения, пока игрок явно не застрял из-за интерфейсной непонятности.
