# Level 01 — Учебная сверка / Training Reconciliation

Роль: обучение Formula Cells 2.0 без `#REF!`.

## Параметры

- Поле: 8×8.
- Goals: `SalaryTotal`, `OvertimeTotal`.
- Ответы: Salary = 318, Overtime = 15.
- `B = 8`.
- `#REF! = off`.
- Formula inventory: `2 SORT + 2 report-SUM`.

## Ключевая геометрия

`B3:B7` и `F3:F7` открыты. `D2` изначально содержит SORT, но его вертикальный spill `D3:D7` блокируют два посторонних Bonus-token в `D4` и `D6`.

Это обучающий spatial choice:

- оставить `D2` и потратить 2 MOVE на blockers;
- или MOVE пустой `D2 =SORT()` в `B2` за 1 действие.

Вторая линия оптимальна и обучает тому, что formula property является перемещаемой частью поля, а не фиксированной кнопкой.

## Минимальная линия

Один из эквивалентных порядков:

1. MOVE `D2 =SORT()` -> `B2`.
2. DROP Salary key `B1` -> `B2 =SORT()`.
3. DROP `B3:B7` -> `H2 =SUM()` => 318.
4. DROP Overtime key `D1` -> `F2 =SORT()`.
5. DROP `F3:F7` -> `H3 =SUM()` => 15.

`C_sem = 4` — две чистые цепочки SORT+SUM при идеальной инфраструктуре.

`C0 = 5`.

`C_spatial = 1` — осмысленный MOVE FormulaCell.

`B = 8`, `R = 3`.

## Formula diagnostics

- `F_act = 4`.
- `F_move = 1`.
- `F_extract = 0`.
- `F_tax = 0`.
- `FHL = (0 + 0.5*1)/5 = 0.10`.

Placement choice здесь намеренно простой: у D2 есть выбор «оставить и расчистить» либо «перенести в свободную lane». Сам MOVE не является декоративным, потому что экономит действие и меняет spill geometry.

Approximate `PL ≈ 19–22`; `AT = 0`.

## Что должен проверить тест

- игрок понимает `Drag = MOVE` и `Shift+Drag = SELECT`;
- ghost ясно показывает, что именно переносится;
- игрок понимает, что пустая формула переносится, а заполненная сначала отдаёт occupant;
- DROP key -> SORT и DROP selected range -> SUM читаются без отдельной кнопки;
- игрок замечает, что выгоднее перенести SORT, чем вручную чистить две клетки;
- уровень ощущается пространственным, а не последовательностью toolbar-команд.
