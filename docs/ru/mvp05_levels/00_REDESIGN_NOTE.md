# MVP 0.5 / Formula Cells 2.0 — четырёхуровневая прогрессия плейтеста

Источник истины для runtime-координат и таймингов: `PrototypeLevelConfig.cs`.

Этот проход намеренно использует только четыре уровня. Прогрессия проверяет по одному вопросу за раз:

1. **Учебная сверка** — освоить `Drag=MOVE`, `Shift+Drag=SELECT`, активацию через DROP и перемещаемые FormulaCell без аномалии.
2. **Сверка под наблюдением** — тот же пазл и те же цели; одно позднее окно `#REF!` создаёт лёгкое давление, но обычно не требует реакции.
3. **Несогласованные данные** — две семантические цели с зависимостью через отчёт; `#REF!` должен заставить примерно 2–3 раза перестроить план за успешный проход. Цель: часто проходить со второй попытки.
4. **Финальная сверка** — композиция из трёх целей под реальным давлением аномалии. Цель: несколько осмысленных перепланирований и примерно 3–4 попытки у чистого нового игрока до освоения.

## Ограничения авторинга FC2

- `MOVE` стоит 1 действие; выделение бесплатно.
- Formula активируется только через DROP.
- Заполненная FormulaCell закреплена, пока occupant не вынесен.
- Пустая FormulaCell может перемещаться.
- Occupant ReportCell является постоянным операндом формулы.
- Дефицит формул не должен становиться налогом обслуживания: предпочтительно `FHL <= 0.25`, а дефицит не должен повышать `C0` более чем примерно на 35% относительно `C_sem` без настоящего пространственного решения.
- Точная сложность аномалии остаётся гипотезой плейтеста до наблюдения детерминированной spawn/intent-трассы в Unity.

Старые пятиуровневые заметки заменены четырьмя authoring sheets в этой директории.
