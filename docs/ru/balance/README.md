## Листы актуальной книги

### Current Levels
Текущие runtime-baseline L1–L4.

Формульные столбцы включают:
- `R = B - C0`;
- `F_tax = max(0,F_extract-F_delivery)`;
- `FHL = (F_tax + 0.5*F_move)/C0`;
- примерное число возможностей outbreak `N_A`.

Значения должны быть заменены после приёмки уровня, пересобранного в Constructor.

### Model
Глоссарий и authoring guardrails.

### Authoring Template
Пустые строки для новых layout. Базовые производные считаются автоматически, но `PCI/SP/SA/WP/Slack/PL/AT` намеренно оставлены для явного анализа: им нужна геометрия/информация об угрозе, а не предположительные числа.

## Политика точности

Не делать таблицу увереннее самой игры.

- `C0` считать точным только после записи законного маршрута.
- Приблизительные baseline помечать как приблизительные.
- `N_A` — оценка ритма, а не число spread.
- `AT` не заполнять «по ощущениям»; для критичных сущностей использовать реальные Unity spawn/intent traces.
- `PL/AT/D` — диагностика, а не цели дизайна.

## Процесс обновления

Принятый constructor export → commit level config → обновить authoring sheet уровня → обновить CSV/workbook → smoke в Unity → затем заполнить наблюдаемые threat/replan notes.
