# EXEL HELL — Prototype Features

## Цель прототипа
Доказать core-loop: **игрок заканчивает отчёт, пока `#REF!` уничтожает необходимые данные**.

Прототип считается успешным, если игроку приходится выбирать между продвижением отчёта и спасением данных.

## P0 — обязательно

### F01. Spreadsheet Grid
- Таблица 10×10.
- Ячейки имеют координату, значение и состояние.
- Состояния: `Normal`, `Corrupted`, `Destroyed`.

### F02. Выделение
- Клик по ячейке.
- Drag выделяет прямоугольный диапазон.
- Выделенный диапазон визуально читаем.

### F03. Пошаговый цикл
- Любое игровое действие тратит 1 ход.
- После действия игрока выполняется ход аномалии.
- Рабочий день ограничен числом ходов.

### F04. SUM
- Игрок выделяет числовой диапазон.
- `SUM` вычисляет сумму и записывает результат в выбранную целевую ячейку.
- Действие тратит ход.

### F05. CUT / PASTE
- `CUT` переносит значение ячейки в Clipboard и очищает исходную ячейку.
- `PASTE` переносит значение из Clipboard в выбранную ячейку.
- `CUT` и `PASTE` — отдельные ходы.

### F06. DELETE
- Уничтожает выбранную ячейку вместе с содержимым.
- Используется для локализации заражения.
- Действие тратит ход.

### F07. Аномалия `#REF!`
- Появляется в заданной ячейке.
- Распространяется после ходов игрока.
- `Normal → Corrupted → Destroyed`.
- Предпочитает клетки с данными, нужными для отчёта.

### F08. Задачи отчёта
- Один уровень содержит 3 обязательных итоговых показателя.
- Для каждого показателя есть целевая ячейка.
- Правильные значения вычисляются из исходных данных таблицы.

### F09. SUBMIT REPORT
- Игрок может отправить отчёт до окончания дедлайна.
- Проверяются три итоговых значения.
- Верный отчёт завершает уровень победой.

### F10. Поражение
- Закончились ходы до успешной отправки отчёта; или
- обязательный показатель стал невосстановим из-за потери данных.

### F11. Минимальный feedback
- Видно выбранные клетки.
- Видно текущий ход / оставшееся время.
- Видно состояния `#REF!` и уничтоженной клетки.
- Видны результат `SUBMIT`, победа и поражение.

### F12. Авторский тестовый уровень
- Один заранее собранный сценарий.
- Первые 2–3 хода безопасны и обучают действиям.
- Затем `#REF!` создаёт реальный конфликт между отчётом и спасением данных.

## Не входит в первый прототип
- настоящий Excel/parser формул;
- `SORT`, `IF`, `COUNT`, `UNDO`;
- другие типы аномалий;
- чат начальника и сюжетные события;
- несколько листов;
- процедурная генерация;
- сохранения;
- музыка, SFX, VFX и polish;
- главное меню и настройки.
